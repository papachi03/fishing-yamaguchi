# サイトを見てもらうための導線（コピペ用）

サイト: https://yamaguchifishing.com/

**このファイルの使い方**：下のコードブロックをそのままコピーして、YouTubeの概要欄・固定コメント・
Instagramのプロフィールに貼るだけ。文言を変えたくなったらこのファイルを直して、また使う。

> ⚠️ **視聴者の方の釣り場は「下関」と書く。** 具体的な地名（港名・地区名）は出さない。
> サイト本体もそう直してあるので、宣伝文だけ具体名が出ると台無しになる。

## 1. リンクは「どこから来たか」が分かる形にする

同じサイトのURLでも、末尾に印を付けておくとGA4で**概要欄から来た人・固定コメントから来た人・
Instagramから来た人**を分けて数えられる。付けなくても動くが、付けないと全部「YouTube経由」に
まとめられて、どの導線が効いたか分からない。

| 貼る場所 | 貼るURL |
|---|---|
| YouTube 概要欄 | `https://yamaguchifishing.com/?utm_source=youtube&utm_medium=description` |
| YouTube 固定コメント | `https://yamaguchifishing.com/?utm_source=youtube&utm_medium=comment` |
| Instagram プロフィール | `https://yamaguchifishing.com/?utm_source=instagram&utm_medium=bio` |
| Instagram ストーリーズ | `https://yamaguchifishing.com/?utm_source=instagram&utm_medium=story` |
| 口頭で伝える時 | `yamaguchifishing.com`（印なしでOK） |

**GA4での見方**：レポート → 集客 → トラフィック獲得 → 「セッションのソース / メディア」。
`youtube / description` と `youtube / comment` が別の行で出てくる。

## 5. ハッシュタグ

YouTubeは**先頭3つだけがタイトル上に表示**され、**15個を超えると全部無効**になる。
10個前後に抑えるのが安全（詰め込むとスパム判定される）。タグ内にスペースや記号（・／！）は使えない。

### 毎回つける固定3つ
```text
#山口県の釣り #堤防釣り #釣りvlog
```

### 釣種で差し替え（2〜4個）
| 回 | 追加するタグ |
|---|---|
| エギング | `#エギング` `#アオリイカ` `#コウイカ` |
| 灯火フィッシング | `#灯火フィッシング` `#CD式灯火` `#ヤリイカ` |
| ヤエン | `#ヤエン` `#アオリイカ` |
| アジング | `#アジング` `#アジ` |
| ショアジギング | `#ショアジギング` `#青物` |
| サビキ・泳がせ | `#サビキ釣り` `#泳がせ釣り` |
| 料理回 | `#釣って食べる` `#魚料理` |

**`#CD式灯火` は特に推し。** ダディ自身が名付けた釣法で他の誰も使っていないので、
毎回付けていくと検索した人が全部まとめて見られる「自分の場所」になる。

### 地名（撮影地に合わせて1〜2個）
```text
#萩市  #長門市  #下関  #日本海
```

### サイトを告知する回だけ追加
```text
#山口フィッシングジャーナル #釣り情報 #潮見表
```

### そのまま貼れる例（灯火フィッシング＋サイト告知の回・10個）
```text
#山口県の釣り #堤防釣り #釣りvlog #灯火フィッシング #CD式灯火 #ヤリイカ #萩市 #日本海 #山口フィッシングジャーナル #釣り情報
```

## 6-2. Instagram告知：下松・防府の追加＋体感のズレを聞く（2026-09-13）

**狙いは2つ。**①エリア追加の告知 ②**「予報の風速と現場の体感のズレ」について意見をもらう**。
②が本題。単なる告知より反応が返るし、返ってきた声はそのまま瀬戸内側のしきい値
（暫定 5/7/10）を確定させる根拠になる。萩の地元の方に聞いて3/5/7にしたのと同じやり方。

**画像（どれか）**
- スマホでSEAページの下松または防府を開いた画面のスクショ（縦。判定バンド＋風速・突風が入る位置）
- 8/25の白波の写真と、凪の写真の2枚組（ズレの話と直結するので強い）
- 画面スクショ1枚＋白波1枚の組み合わせがいちばん伝わる

**キャプション（そのままコピー）**

```text
予報「風速3m」の日に堤防に立ったら、体感は5mありました🌬️

釣りに行く前の海況をまとめたサイトに、下松と防府を追加しました。
友人から「瀬戸内側も見たい」と言ってもらえたのがきっかけです。

▼追加したもの
・下松（潮汐は徳山の観測点）
・防府（潮汐は市内の三田尻。いちばん地点が近い）
・風向・風速・突風・波の高さ・潮の満ち引き
・「今日は堤防に立てるか」の4段階判定（安全→注意→危険→中止）

ここで皆さんに聞きたいことがあります。

予報の風速って、現場だと強く感じませんか？
自分の感覚では表示より+2mくらい強いです。
萩で釣りをされてる方にも「3mを超えると厳しい」と言われて、
日本海側は基準を厳しめ（3m超で注意／5m超で危険／7m超で中止）に直しました。

ただ瀬戸内側は波が立ちにくいぶん、同じ基準だと厳しすぎる気がしていて、
いまは暫定の数字を入れています。

・予報が何mの日から「今日はきついな」と感じますか？
・下松・防府あたりで釣りをされてる方の体感も知りたいです

コメントで教えてもらえると助かります🙏
実際に立ってる人の感覚がいちばん正確なので、いただいた声を基準に反映させます。

サイトはプロフィールのリンクから見られます。

#山口県の釣り #堤防釣り #下松市 #防府市 #周南 #瀬戸内海 #周防灘
```

**ハッシュタグの考え方**
- **`#下松市` `#防府市` `#周南` を必ず入れる。** 今回届けたいのはその地域の人。地名タグは
  フォロワー以外に届く数が一番多い
- `#瀬戸内海` `#周防灘` は今回の追加内容そのもの。日本海側の既存タグと併記して

## 7. 進め方 ── まず1本だけ試す（2026-09-12 ダディ承認）

3本まとめて貼ってから「文言が刺さらない」と分かると3回貼り直しになるので、
**再生数1位の1本だけ**に貼って反応を見てから展開する。

### STEP 1（いま）対象はこの1本
**【ヤリイカ】明かりはNGの常識を覆す新ヤリイカ釣法【灯火フィシング】**
6.8万回 / 36:55 / https://www.youtube.com/watch?v=gc1c6fg2hU0

YouTube Studio → コンテンツ → この動画 → 詳細

1. **説明の一番上**にこの1行を入れる（折りたたみ状態でも見える位置）
   ```text
   🎣 釣りに行く前の海況チェック → https://yamaguchifishing.com/?utm_source=youtube&utm_medium=description
   ```
2. **説明の一番下**に §2 の枠をまるごと貼る（既存の文章は消さない）
3. 「保存」
4. 動画ページへ行き、§3 の固定コメントを投稿 → 自分のコメントの「︙」→ **固定**

### STEP 2（2〜3日後・9/15目安）GA4で確認
レポート → 集客 → トラフィック獲得 → 「セッションのソース / メディア」

- `youtube / description` … 概要欄から来た人
- `youtube / comment` … 固定コメントから来た人

**数字の目安**：概要欄の外部リンクは押される率が低く、**1日1〜10クリック程度が普通**。
数十人来たら大成功、0が3日続くようなら文言か置き場所を見直す。
「少ないから失敗」と早合点しないこと（古い動画の1日の再生数 × 1%前後が相場）。

## 8. 伸ばすための考え方（メモ）

- **「釣りに行く前に見るサイト」の一点で押す。** 釣果の見せ場は動画側にあるので、サイトは"実用"を
  看板にしたほうが刺さる。海況・安全判定・潮は毎日使う理由になる
- **視聴者の方への感謝として触れると効く。**「教えてもらってるので、そこの海況も載せました」
  （ただし場所は「下関」まで）
- **URLが長いのが唯一の弱点。** 口頭で伝えられないので、独自ドメイン（例 `yamaguchi-fishing.jp`、
  年1,000〜3,000円）にすると動画内で言える。その時は `.github/workflows/deploy.yml` の
  `SITE_BASE` を `/` に、`index.html` の `og:image` を新ドメインに直す（DEPLOY_GITHUB.md 参照）
