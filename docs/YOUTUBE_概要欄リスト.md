## やり方（1本30秒）

1. 「Studioで開く」を押す（YouTube Studioの編集画面が開く）
2. **説明欄の一番上**に、その動画の「貼る1行」をコピペ
3. 右上の「保存」

- 行末の `utm_content=` の後ろが**動画ごとに違う**。GA4で「どの動画から来たか」を見分けるための印なので、**必ずその動画の行を使う**（使い回さない）
- 既存の説明文は消さない。一番上に1行足すだけ
- ショート動画には貼らない（YouTubeの仕様でリンクが押せない）
- **固定コメントは再生数が多い上位3本だけ**（済み）。再生数の少ない動画には付けなくてよい
- 並びは「再生数が分かっている人気上位 → サイトのJOURNALに載せている動画 → 最新の釣り動画」の順。**時間が無ければ上から**

## GA4での見方

レポート → 集客 → トラフィック獲得 → 表の見出しの「＋」から **「セッションの手動広告コンテンツ」** を追加。
動画IDごとに訪問数が並ぶ。IDとタイトルの対応はこのリストで引く。
